## 四、常见问题

| 现象 | 原因与处理 |
|---|---|
| 登录提示"验证码错误或已过期" | 验证码 5 分钟有效、一次性；点击图片刷新后重新输入（不区分大小写） |
| 登录提示"请求过于频繁" | 登录接口限流 **5 次/分钟/IP**，等待 1 分钟后重试 |
| 提示"账号已被禁用" | 该账号被管理员禁用（admin 在「用户管理/系统设置」可重新启用） |
| shelter3 登录后看不到数据 | 该机构入驻待审核，审核通过后才有工作台数据（正常演示流程） |
| 微信开发者工具请求失败 | 勾选「详情 → 本地设置 → 不校验合法域名」，并确认 `common/config.js` 的 BASE_URL 指向 8080 |
