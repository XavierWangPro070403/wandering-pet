## 复用规范

- 按钮 3 种（主/次/文字）全站一套，40 高 8px 圆角，主色底深墨字；
- 卡片唯一形态（16 圆角 1px 边 shadow-1），可点卡片 hover 上浮 2px + 图内放大 1.03；
- 状态标签 = 圆点 + 文字（§8.2 五组色对），StatusTag 全站唯一实现；
- 空态 EmptyState（发生了什么 + 下一步按钮）、加载骨架屏、错误重试三态齐全；
- 动效仅三层：首屏入场一次（≤1.1s）、故事章节 sticky 照片记忆点、hover/press/focus 反馈；`prefers-reduced-motion` 全部静止；
- 数字全部 `tabular-nums`，金额 `¥ x.xx`，时间 `yyyy-MM-dd HH:mm:ss`。
